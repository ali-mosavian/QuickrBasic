# Help Menu
keys: Help Menu

Commands that show help.

    Index  Contents  Topic: (F1)  Using Help (Shift+F1)  About...

See also [Index Command](Index Command), [Contents Command](Contents Command).

## Details
    Index          every topic
    Contents       the table of contents
    Topic:         F1, help on the word at the cursor
    Using Help     Shift+F1
    About...       version box

Each item has its own topic: [Topic Command](Topic Command),
[Using Help Command](Using Help Command), [About Command](About Command).

## Example
    Put the cursor on  PRINT  in the program
    F1             the PRINT topic opens
    Esc            close; Alt+H, C opens the contents
