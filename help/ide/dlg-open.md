# Open Dialog
keys: Open Dialog

Opened by [Open Command](Open Command): choose a program to load.

See also [Save As Dialog](Save As Dialog), [dialog boxes](dialog boxes).

## Details
    File Name     type a name or a pattern such as *.BAS
    Files         the matching files, sorted, in three columns
    Dirs/Drives   folders and drives; the path is shown above Files

Tab moves between the three. In Files, Enter on a name loads it.
In Dirs/Drives, Enter changes folder and refreshes Files. Typing a
pattern in File Name and pressing Enter lists only those files. A
name with no extension gets .BAS.

OK loads; Cancel and Esc leave; Help shows this topic.

## Example
    Alt+F, O       the box opens
    type  *.TXT    Enter: Files lists only .TXT files
    Tab            to Files; Down to a name; Enter loads it
