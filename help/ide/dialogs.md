# Dialog Boxes
keys: dialog boxes, dialog box, dialogs

A dialog box asks for something before a command goes on.

    Tab, Shift+Tab   next, previous control
    Alt+letter       the control with that letter lit
    Enter            the default button (OK)
    Esc              Cancel
    Up, Down         move in a list
    Space            tick or clear a check box

Controls:
- A text field. When you enter it its text is selected; type to
  replace it, or press an arrow to edit it.
- A list. Up and Down choose; Enter takes the item.
- A check box, marked with X.
- A button. Choose it with Enter or a click.

The Help button shows the box's topic.
