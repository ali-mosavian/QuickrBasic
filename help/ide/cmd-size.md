# Display Size Command
keys: Display Size Command, display size, 25 lines, 43 lines, 50 lines, 25 Lines Command, 43 Lines Command, 50 Lines Command, 132 columns, VESA text modes, Display Dialog

Options, Display Size

Sets the editor's columns and lines: a text mode the card has.

See also [Theme Command](Theme Command), [Options Menu](Options Menu).

## Details
The Display Size sub-menu lists 80 x 25, 80 x 43 and 80 x 50, then the
card's VESA text modes, such as 132 x 43; the current size is bulleted.
A bigger screen shows more of the program at once. The program's own
screen modes are not affected.

## Example
    Alt+O, Z       open the Display Size sub-menu
    Down, Enter    choose 80 x 43: the editor grows to 43 rows
