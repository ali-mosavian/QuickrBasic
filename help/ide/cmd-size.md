# Display Size Command
keys: Display Size Command, display size, 25 lines, 43 lines, 50 lines, 25 Lines Command, 43 Lines Command, 50 Lines Command, Display Dialog

Options, Display Size

Sets the editor's height: 25, 43 or 50 lines of 80 columns.

See also [Theme Command](Theme Command), [Options Menu](Options Menu).

## Details
The Display Size sub-menu lists 25 Lines, 43 Lines and 50 Lines; the
current size is bulleted. A taller screen shows more of the program
at once. The program's own screen modes are not affected.

## Example
    Alt+O, D       open the Display Size sub-menu
    Down, Enter    choose 43 Lines: the editor grows to 43 rows
