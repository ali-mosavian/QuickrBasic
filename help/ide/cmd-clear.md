# Clear Command
keys: Clear Command

Edit, Clear    Del

Removes the selected text without touching the clipboard.

See also [Cut Command](Cut Command).

## Details
The selection is deleted and the clipboard keeps what it held, so a
later Paste still inserts the earlier text. Dim when nothing is
selected. In the text, Del does the same thing.

## Example
    Shift+Right x5   select five characters
    Del              they are gone; the clipboard is unchanged
