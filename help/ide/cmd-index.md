# Index Command
keys: Index Command

Help, Index

Lists every topic by name.

See also [Contents Command](Contents Command).

## Details
Shows the Index, built from every key of every topic: keywords,
phrases and error messages. Up and Down choose, PgUp and PgDn move a
page, Enter shows the topic. Typing letters jumps to the first name
that starts with them.

## Example
    Alt+H, I       open the Index
    type  PRINT    the list jumps to PRINT
    Enter          show the PRINT topic
