# Output Screen Command
keys: Output Screen Command

View, Output Screen    F4

Shows what the program has printed or drawn.

See also [immediate window](immediate window).

## Details
The output screen is where a running program writes. Press F4 to look
at it between runs or at a stop. Any key returns to the editor. Output
from statements typed in the immediate window appears here too.

## Example
    Shift+F5       run  PRINT "Hi"
    any key        back to the editor
    F4             look at the output again: Hi
