# Find Dialog
keys: Find Dialog

Opened by [Find Command](Find Command): the text to look for.

See also [Repeat Last Find Command](Repeat Last Find Command),
[Change Dialog](Change Dialog).

## Details
    Find What                 the text to look for
    Match Upper/Lowercase     case must agree
    Whole Word                not part of a longer word

A whole word has no letter, digit or one of ! # $ % & . beside it.
OK finds the first match after the cursor and selects it. F3 repeats
the search later.

## Example
    Alt+S, F       open the box
    type  count    Enter: the next  count  is selected
    With Whole Word ticked, "counter" is not a match.
