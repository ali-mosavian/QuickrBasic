# Survival Guide
keys: survival, survival guide

The editor in one page. Everything has a keyboard and a mouse way.

## Menus
Tap Alt, or press Alt plus a title's letter (Alt+F for File).
Left and Right change menu, Up and Down choose, Enter runs the
item, Esc leaves. A letter picks the item with that letter lit.
With the mouse, click a title, then an item. See [menus](menus).

## Dialog boxes
Tab and Shift+Tab move between controls, Alt+letter jumps to one,
Enter presses the default button, Esc cancels, Space ticks a
check box. See [dialog boxes](dialog boxes).

## Keys worth knowing
    F1          help on the word at the cursor
    F2          SUBs list              F3   repeat last find
    F4          output screen          F5   continue
    Shift+F5    start the program      F6   next window
    F7          step over              F8   step
    F9          breakpoint on or off   Shift+F8   step out

## Selecting text
Hold Shift and move, or drag with the mouse. Then Shift+Del
cuts, Ctrl+Ins copies, Shift+Ins pastes, Del clears.
See [selecting text](selecting text).

## Windows
F6 moves between the program window, the second window and the
immediate window. See [windows](windows) and
[immediate window](immediate window).

## Getting out
File, Exit. If the program changed you are asked to save it.

See also [editing keys](editing keys), [mouse](mouse),
[shortcut keys](shortcut keys), [using help](using help).
