# Cut Command
keys: Cut Command

Edit, Cut    Shift+Del

Removes the selected text and puts it on the clipboard.

See also [Paste Command](Paste Command), [selecting text](selecting text).

## Details
The clipboard holds one piece of text; Cut replaces what it held.
Dim when nothing is selected. To remove text without changing the
clipboard use [Clear Command](Clear Command).

## Example
    Shift+Down     select the current line
    Shift+Del      cut it
    Down           move to another line
    Shift+Ins      paste it there
