# Contents Command
keys: Contents Command

Help, Contents

Shows the table of contents.

See also [Index Command](Index Command), [using help](using help).

## Details
Opens the help window on the first topic, the table of contents. Each
line is a link to a part of the help. Tab moves to the next link and
Enter follows it. The help window's own Contents button does the same.

## Example
    Alt+H, C       open the table of contents
    Tab            move to the next link
    Enter          follow it
    Esc            close the help window
