# SUBs Command
keys: SUBs Command

View, SUBs...    F2

Lists the program's main module and every SUB and FUNCTION.

See also [View Menu](View Menu).

## Details
The list, sorted by name, is in the [SUBs Dialog](SUBs Dialog). From
it you can show a procedure in the active or the second window, or
delete it.

Shift+F2 and Ctrl+F2 step to the next and previous view without the
box.

## Example
    F2             the list opens
    Down           choose Greet
    Enter          show it in the active window
    Shift+F2       on to the next procedure
