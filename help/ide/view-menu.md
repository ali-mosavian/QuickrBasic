# View Menu
keys: View Menu

Commands that choose what is on the screen.

    SUBs... F2   Split   Split Vertically   Output Screen F4

See also [SUBs Command](SUBs Command), [Split Command](Split Command).

## Details
    SUBs...             F2
    Split
    Split Vertically
    Output Screen       F4

Each item has its own topic:
[Split Vertically Command](Split Vertically Command),
[Output Screen Command](Output Screen Command).

## Example
    F2             choose a SUB from the list
    Alt+V, S       split the window
    F4             look at the output screen
