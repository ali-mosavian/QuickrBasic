# SUBs Dialog
keys: SUBs Dialog

Opened by [SUBs Command](SUBs Command): "Choose program item to edit".

See also [dialog boxes](dialog boxes).

## Details
A list holds the module first, then each SUB and FUNCTION by name.

    Edit in Active   show it in the current window
    Edit in Split    show it in the second window
    Delete           delete the procedure (asks to confirm)
    Cancel           leave

## Example
    F2             the list opens
    Down           choose Greet
    Alt+S          Edit in Split: Greet shows in the second window
