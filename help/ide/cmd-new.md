# New Command
keys: New Command

File, New

Starts an empty, Untitled program.

See also [File Menu](File Menu), [Save Command](Save Command).

## Details
If the current program has unsaved changes you are asked first: Yes
saves it, No drops it, Cancel keeps working. All procedures of the
old program are cleared, along with its breakpoints.

## Example
    Alt+F, N       File, New
    "Loaded file is not saved. Save it now?" appears
    N              drop the old program; the window is Untitled
