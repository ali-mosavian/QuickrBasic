# Help Path Command
keys: Help Path Command

Options, Help Path...

Dim: not available.

See also [Options Menu](Options Menu).

## Details
The help file BASIC.HLP is read from the directory of the program
itself, so there is no path to set. The item is shown dim and does
nothing. QBasic let you name a directory here; QuickrBasic does not.

## Example
    Alt+O          open Options
    Down           the Help Path... item is dim and cannot be chosen
    Place BASIC.HLP beside the program instead
