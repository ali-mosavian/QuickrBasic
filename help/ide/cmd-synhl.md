# Syntax Highlighting Command
keys: Syntax Highlighting Command, syntax highlighting

Options, Syntax Highlighting

Toggles colouring of keywords, strings, numbers and comments.

See also [Syntax Checking Command](Syntax Checking Command),
[Theme Command](Theme Command).

## Details
The colours come from the same scanner the compiler uses, so they
never disagree with it. A bullet means on. The colours are those of
the [Theme Command](Theme Command). Highlighting is separate from
syntax checking and does not report errors.

## Example
    Alt+O, H       toggle: the bullet appears or goes
    The program text is coloured while the bullet is shown
