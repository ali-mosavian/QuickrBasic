# Copy Command
keys: Copy Command

Edit, Copy    Ctrl+Ins

Puts the selected text on the clipboard and leaves it in place.

See also [Paste Command](Paste Command), [selecting text](selecting text).

## Details
The clipboard holds one piece of text; Copy replaces what it held.
Dim when nothing is selected. The text stays in the program and the
selection stays on.

## Example
    Shift+Down     select the current line
    Ctrl+Ins       copy it
    Shift+Ins      paste: the line now appears twice
