# Save As Command
keys: Save As Command

File, Save As...

Saves under a name you choose.

See also [Save Command](Save Command).

## Details
The [Save As Dialog](Save As Dialog) takes the name and the folder.
The program takes that name afterwards. If the file exists, you are
asked whether to overwrite it.

## Example
    Alt+F, A       the Save As box opens
    type  demo     then Enter: written as DEMO.BAS
