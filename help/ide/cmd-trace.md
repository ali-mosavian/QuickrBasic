# Trace On Command
keys: Trace On Command

Debug, Trace On

Toggles tracing, shown with a bullet.

See also [Debug Menu](Debug Menu).

## Details
While on, the statement being run is highlighted in the program as it
executes, so you can watch the flow. The program runs more slowly.
Turn it off with the same command.

## Example
    Alt+D, T       Trace On: a bullet appears
    Shift+F5       each statement lights up as it runs
