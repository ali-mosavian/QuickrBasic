# Syntax Checking Command
keys: Syntax Checking Command

Options, Syntax Checking

Toggles the check of each line as you leave it.

See also [syntax checking](syntax checking).

## Details
A bullet means on. When on, a line with an error is kept as typed,
its error lit; Ctrl+F8 goes to the next one. Checking also
capitalises keywords and cuts trailing spaces.

## Example
    Alt+O, C       toggle checking
    Type  PRINT (  then press Down
    The line end is lit; the status bar names the error
