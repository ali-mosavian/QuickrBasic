# Syntax Checking Command
keys: Syntax Checking Command

Options, Syntax Checking

Toggles the check of each line as you leave it.

See also [syntax checking](syntax checking).

## Details
A bullet means on. When on, a line with an error shows a message box
and the cursor stays on the line. Turn it off to move on without
fixing. Checking also capitalises keywords and cuts trailing spaces.

## Example
    Alt+O, C       toggle checking
    Type  PRINT (  then press Down
    A message box names the error and the cursor stays
