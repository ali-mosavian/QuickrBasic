# Paste Command
keys: Paste Command

Edit, Paste    Shift+Ins

Inserts the clipboard at the cursor.

See also [Cut Command](Cut Command), [Copy Command](Copy Command).

## Details
Dim until something has been cut or copied. The text goes in at the
cursor; with a selection active it replaces the selection. The
clipboard is kept, so you can paste again.

## Example
    Shift+Down     select a line
    Ctrl+Ins       copy it
    Shift+Ins      paste it
    Shift+Ins      paste it again
