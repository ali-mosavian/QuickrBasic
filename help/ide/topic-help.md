# Topic Help
keys: Topic Command, Topic:, topic help, context help

F1 shows help on what the cursor is on.

See also [Help Menu](Help Menu), [Index Command](Index Command).

## Details
- a keyword in the program: its topic.
- an open menu item or dialog box: its topic.

Put the cursor inside the word, or just after it. If the word has no
topic, the Index opens instead.

## Example
    Cursor inside  PRINT  in the program
    F1             the PRINT topic opens
    Alt+F, then F1 on Open...: the Open Command topic opens
