# Search Menu
keys: Search Menu

Commands that find and change text in the program.

    Find...  Repeat Last Find (F3)  Change...

See also [Find Command](Find Command), [Change Command](Change Command).

## Details
    Find...             look for text
    Repeat Last Find    F3
    Change...           find and replace

Repeat Last Find has its own topic:
[Repeat Last Find Command](Repeat Last Find Command).

## Example
    Alt+S, F       Find: type  PRINT  Enter
    F3             next match
    Alt+S, C       Change: replace text
