# New SUB Dialog
keys: New SUB Dialog, New FUNCTION Dialog

Opened by [New SUB Command](New SUB Command) and
[New FUNCTION Command](New FUNCTION Command): the procedure's name.

See also [SUBs Dialog](SUBs Dialog).

## Details
One field, Name: type the procedure's name, then OK.

Cancel, or an empty name, makes nothing.

## Example
    Alt+E, S       the box opens
    type  Greet    Enter: a window with SUB Greet / END SUB opens
