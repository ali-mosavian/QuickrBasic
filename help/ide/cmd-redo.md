# Redo Command
keys: Redo Command, redo

Edit, Redo    Ctrl+Shift+Z

Makes again the change Undo took back.

See also [Undo Command](Undo Command).

## Details
Redo goes forward through what Undo took back, one step at a time.
Any new change ends what can be redone.

## Example
    Ctrl+Z         a line pasted is gone
    Ctrl+Shift+Z   it is back
