# Open Command
keys: Open Command

File, Open...

Loads a program.

See also [File Menu](File Menu).

## Details
The [Open Dialog](Open Dialog) lets you choose the file. Unsaved
changes to the current program are asked about first. A name that does
not exist gives "File not found". A name with no extension gets .BAS.

## Example
    Alt+F, O       the Open box appears
    type  hello    then Enter: loads HELLO.BAS
    Shift+F5       run it
