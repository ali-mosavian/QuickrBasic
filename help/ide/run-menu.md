# Run Menu
keys: Run Menu

Commands that run the program.

    Start Shift+F5   Restart   Continue F5

See also [Start Command](Start Command), [Debug Menu](Debug Menu).

## Details
    Start       Shift+F5
    Restart
    Continue    F5

Each item has its own topic: [Restart Command](Restart Command),
[Continue Command](Continue Command).

## Example
    Type:   PRINT "Hi"
    Shift+F5       run it; the output screen shows Hi
    any key        back to the editor
