# Split Command
keys: Split Command

View, Split

Divides the program area into two windows, one above the other.

See also [Split Vertically Command](Split Vertically Command),
[windows](windows).

## Details
Both windows show the program, and each can show a different
procedure, so two places can be seen at once. F6 moves between
windows. Drag the line between them, or use Alt+Plus and Alt+Minus,
to change their heights. Lines can be dragged between them.

## Example
    Alt+V, S       Split: a second window opens below
    F2             pick a SUB; Alt+S in the box shows it
                   in the second window
    F6             move between the two
