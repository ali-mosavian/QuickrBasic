# Edit Menu
keys: Edit Menu

Commands that move text through the clipboard and make
procedures.

    Cut          Shift+Del
    Copy         Ctrl+Ins
    Paste        Shift+Ins
    Clear        Del
    New SUB...
    New FUNCTION...
