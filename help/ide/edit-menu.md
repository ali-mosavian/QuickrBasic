# Edit Menu
keys: Edit Menu

Commands that undo changes, move text through the clipboard and make
procedures.

    Undo Ctrl+Z   Cut Shift+Del   Copy Ctrl+Ins   Paste Shift+Ins

See also [selecting text](selecting text).

## Details
    Undo         Ctrl+Z
    Redo         Ctrl+Shift+Z
    Cut          Shift+Del
    Copy         Ctrl+Ins
    Paste        Shift+Ins
    Clear        Del
    New SUB...
    New FUNCTION...

Each item has its own topic: [Undo Command](Undo Command),
[Redo Command](Redo Command), [Cut Command](Cut Command),
[Copy Command](Copy Command), [Paste Command](Paste Command),
[Clear Command](Clear Command), [New SUB Command](New SUB Command),
[New FUNCTION Command](New FUNCTION Command).

## Example
    Shift+Down     select a line
    Ctrl+Ins       copy it
    Shift+Ins      paste: the line is doubled
