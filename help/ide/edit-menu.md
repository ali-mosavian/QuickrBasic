# Edit Menu
keys: Edit Menu

Commands that move text through the clipboard and make procedures.

    Cut Shift+Del   Copy Ctrl+Ins   Paste Shift+Ins   Clear Del

See also [selecting text](selecting text).

## Details
    Cut          Shift+Del
    Copy         Ctrl+Ins
    Paste        Shift+Ins
    Clear        Del
    New SUB...
    New FUNCTION...

Each item has its own topic: [Cut Command](Cut Command),
[Copy Command](Copy Command), [Paste Command](Paste Command),
[Clear Command](Clear Command), [New SUB Command](New SUB Command),
[New FUNCTION Command](New FUNCTION Command).

## Example
    Shift+Down     select a line
    Ctrl+Ins       copy it
    Shift+Ins      paste: the line is doubled
