# Windows
keys: windows

Up to three windows: the program, a second program window and the
immediate window.

See also [Split Command](Split Command), [immediate window](immediate window).

## Details
The screen holds up to three windows: the program window, a second
program window made by Split, and the immediate window at the
bottom. After a stop, a [debug pane](debug pane) sits to their right.

    F6, Shift+F6   next, previous window
    Alt+Plus       window one row taller
    Alt+Minus      window one row shorter
    Ctrl+F10       maximise the window; again to restore
    Shift+F2       next procedure view   Ctrl+F2   previous

The grey Plus and Minus keys work too. With the mouse, drag a
window's title row up or down, drag the line between two windows
side by side, or drag the debug pane's border.

Each program window shows one module or procedure, so two windows
can show two places in one program. Lines can be dragged between
them. See also [Split Vertically Command](Split Vertically Command).

## Example
    Alt+V, S       split: two program windows
    F6             move to the lower one
    Alt+Plus       make it one row taller
    Ctrl+F10       maximise it; again to restore
