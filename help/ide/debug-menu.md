# Debug Menu
keys: Debug Menu

Commands for stepping through a program and stopping it.

    Step                      F8
    Step Over                 F7
    Step Out                  Shift+F8
    Trace On
    Toggle Breakpoint         F9
    Clear All Breakpoints
    Set Next Statement

Ctrl+F7 (no menu item) runs to the cursor's line.
