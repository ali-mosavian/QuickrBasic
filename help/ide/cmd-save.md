# Save Command
keys: Save Command

File, Save

Writes the program to its file.

See also [Save As Command](Save As Command).

## Details
The program is written under its current name. An Untitled program
has no name yet, so Save opens the [Save As Dialog](Save As Dialog).
A file that cannot be written gives "Path/File access error".

## Example
    Alt+F, S       on a loaded HELLO.BAS: saved at once
    Alt+F, S       on an Untitled program: the Save As box opens
