# File Menu
keys: File Menu

Commands that load, save and leave programs.

    New  Open...  Save  Save As...  Print...  Exit

See also [New Command](New Command), [Open Command](Open Command).

## Details
    New          clear the program
    Open...      load a program
    Save         save under its name
    Save As...   save under a new name
    Print...     not available yet
    Exit         leave QuickrBasic

Each item has its own topic: [New Command](New Command),
[Open Command](Open Command), [Save Command](Save Command),
[Save As Command](Save As Command), [Print Command](Print Command),
[Exit Command](Exit Command).

## Example
    Alt+F          open File
    Down, Enter    choose an item
    or Alt+F, S    Save by its lit letter
