# Restart Command
keys: Restart Command

Run, Restart

Sets the program to stop on its first statement.

See also [Step Command](Step Command), [Start Command](Start Command).

## Details
Clears all variables and readies the program to be stepped from the
top. Nothing runs until you press a step key or F5. Watches and
breakpoints are kept.

## Example
    Alt+R, R       Restart
    F8             step: stopped on the first statement
    F8             and the next, one at a time
