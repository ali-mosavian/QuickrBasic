# Split Vertically Command
keys: Split Vertically Command

View, Split Vertically

Like Split, but the two windows sit side by side.

See also [Split Command](Split Command), [windows](windows).

## Details
Both windows show the program, and each can show a different
procedure. Drag the line between them to change their widths. F6
moves between windows.

## Example
    Alt+V, V       the program area splits into left and right
    F6             move to the other window
    F2             show a different SUB there
