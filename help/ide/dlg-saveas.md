# Save As Dialog
keys: Save As Dialog

Opened by [Save As Command](Save As Command), or by Save on an
Untitled program.

    File Name     the new name; .BAS is added if you give none
    Dirs/Drives   the folder to save in

If the file exists, "File already exists. Overwrite?" asks Yes or
No. A name that cannot be written gives "Path/File access error".

See also [Open Dialog](Open Dialog), [dialog boxes](dialog boxes).
