# Mouse
keys: mouse, mouse keys, clicking

Only the left button is used.

    Click a menu title, then an item    runs it
    Click in text                       moves the cursor
    Drag in text, or Shift+click        selects
    Click a window                      focuses it
    Click or drag a scroll bar          scrolls
    Click a status-bar key              same as pressing it
    Drag a title row or border          resizes windows
    Click in a dialog                   press, tick, choose
    Rest on a variable (debugging)      shows its value

A program can read the mouse itself with [PEN](PEN).

See also [survival](survival), [windows](windows).
