# Options Menu
keys: Options Menu

Commands that set how the editor looks and checks.

    Theme  Display Size  Syntax Highlighting  Syntax Checking

See also [Theme Command](Theme Command),
[Display Size Command](Display Size Command).

## Details
    Theme                 nine colour schemes
    Display Size          25, 43 or 50 lines
    Syntax Highlighting   colour the text
    Help Path...          not available yet
    Syntax Checking       check each line

Each item has its own topic:
[Syntax Highlighting Command](Syntax Highlighting Command),
[Help Path Command](Help Path Command),
[Syntax Checking Command](Syntax Checking Command).

## Example
    Alt+O          open Options
    Down, Enter    choose an item; a bullet marks options that are on
