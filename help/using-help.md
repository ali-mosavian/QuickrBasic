# Using Help
keys: using help, help, F1, how to use help

Help opens in its own window with a topic's title in the border. This
topic says how to move around in it.

## Getting a topic
- F1 with the cursor on a keyword shows that keyword's topic.
- F1 with the cursor on nothing shows [Contents](contents).
- Shift+F1 opens Help on Help: this topic.
- In a dialog or menu, F1 shows the topic for that item.
- After an error message, F1 explains that error.

## Moving in a topic
Arrow keys, PgUp, PgDn, Home and End scroll the text. The mouse wheel
and the scroll bar do the same.

## Hot links
A word between arrows, like ◄Contents►, is a hot link.
- Tab moves to the next link, Shift+Tab to the previous one.
- Typing a letter jumps to the next link that starts with it.
- Enter, or a click, follows the highlighted link.

## Going between topics
- Alt+F1 goes back to the topic you came from.
- Ctrl+F1 shows the next topic in the file, Shift+Ctrl+F1 the previous.
- Esc closes the Help window and returns to your program.

## Finding things
Choose Index on the Help menu for every keyword, listed in order. Type
a few letters to jump, then press Enter. Choose Contents for the
[table of contents](contents), the best place to start.
