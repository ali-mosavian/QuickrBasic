# ABS Function
keys: ABS

Syntax
    ABS(n)

Returns the absolute value of the numeric expression n: n itself
when it is zero or more, -n when it is less. The result has n's
type.

## Example
    PRINT ABS(-7.5), ABS(3)

prints 7.5 and 3.
