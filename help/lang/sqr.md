# SQR Function
keys: SQR

Syntax
    SQR(numexpr)

Returns the square root of numexpr. The result is SINGLE, or DOUBLE
if numexpr is DOUBLE. A negative argument is an Illegal function
call.

## Example
    PRINT SQR(16); SQR(2)               ' 4  1.414214
