# BEEP Statement
keys: BEEP

Syntax
    BEEP

Sounds a short tone, the same as PRINT CHR$(7).

See also [SOUND](SOUND), [PLAY](PLAY)

## Details
Sounds a short tone, the same as PRINT CHR$(7).

Use SOUND for a tone of chosen pitch and length, PLAY for music.

## Example
    PRINT "Done"
    BEEP                 ' a short tone
