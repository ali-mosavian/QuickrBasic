# TAN Function
keys: TAN

Syntax
    TAN(angle)

Returns the tangent of angle, given in radians. The result is SINGLE,
or DOUBLE if angle is DOUBLE. It grows without bound near odd
multiples of pi / 2.

## Example
    PRINT TAN(3.141593 / 4)             ' 1
