# Out of memory
keys: Out of memory, error 7

Error 7

## Cause

The program, its arrays and its strings need more memory than the
machine can give.

## Remedy

Use smaller or fewer arrays, free them with [ERASE](ERASE), or shrink
a dynamic array with [REDIM](REDIM).

See also: [DIM](DIM), [ERASE](ERASE), [REDIM](REDIM)
