# Subprogram error
keys: Subprogram error, error 240

Error 240

## Cause

A SUB or FUNCTION is defined in a way not allowed, such as inside
another procedure, or its DECLARE does not agree with it.

## Remedy

Define procedures at module level, and make the DECLARE match the
heading.

See also: [SUB](SUB), [FUNCTION](FUNCTION), [DECLARE](DECLARE)
