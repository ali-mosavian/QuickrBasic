# Function not defined
keys: Function not defined, ~Function not defined /declared, error 18

Error 18

## Cause

A call names a FUNCTION or DEF FN that does not exist above this line,
or one that is DECLAREd but never defined.

## Remedy

Write the [FUNCTION](FUNCTION) or [DEF FN](DEF FN), or fix the name.
Define or [DECLARE](DECLARE) it before its first use.

See also: [FUNCTION](FUNCTION), [DEF FN](DEF FN), [DECLARE](DECLARE)
