# File not found / Path not found
keys: File not found, Path not found, ~Path/File access error, error 53, error 75, error 76

Errors 53, 75 and 76

## Cause

The file or directory named does not exist, or cannot be reached in
that path.

## Remedy

Check the spelling and the current directory. Test with [FILES](FILES)
or by opening the file and trapping the error.

See also: [OPEN](OPEN), [FILES](FILES), [CHDIR](CHDIR)
