# Parameter type mismatch
keys: Parameter type mismatch, error 244

Error 244

## Cause

An argument is not exactly the type of the parameter. A variable is
passed by reference, so no conversion is made.

## Remedy

Pass a variable of the declared type, or wrap the argument in
parentheses to pass its value, converted.

See also: [SUB](SUB), [FUNCTION](FUNCTION), [DECLARE](DECLARE)
