# Statement unrecognizable
keys: Statement unrecognizable

The line begins with something that is not a statement or label.

See also: [keyword lists](keyword lists)

## Details

Cause: The line begins with something that is not a statement, label
or known name.

Remedy: Check the spelling, and that the name is not a reserved word.

Misspelled keywords are the usual cause.

## Example
    PRNT "hi"           ' error
    PRINT "hi"           ' hi
