# $Metacommand Error
keys: $Metacommand Error, Form variable already in use or illegal form name, Form variable already in use or illegal

## Cause

A metacommand comment is written wrong: `'$INCLUDE: 'file'` without
its quotes, `$LINESIZE` without a size, or a bad `$FORM` name.

## Remedy

Match the form in the metacommand topic.

See also: [metacommands](metacommands)
