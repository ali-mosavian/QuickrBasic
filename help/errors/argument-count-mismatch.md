# Argument-count mismatch
keys: Argument-count mismatch, error 37

Error 37

## Cause

A call gives a different number of arguments than the SUB or FUNCTION
has parameters.

## Remedy

Compare the call with the parameter list in the procedure's heading
and the DECLARE.

See also: [SUB](SUB), [FUNCTION](FUNCTION), [DECLARE](DECLARE)
